Frontier-level models are now blowing past the trillion-parameter mark. And despite significant optimizations in inference, the urgent need for memory capacity is exploding with it. While small models continue to improve, high-bandwidth memory based on DRAM on classic GPUs is still the go-to for running these colossal models.
