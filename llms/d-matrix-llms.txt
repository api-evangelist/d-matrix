# d-Matrix

> d-Matrix builds ultra-low-latency, energy-efficient AI inference infrastructure for generative AI in the datacenter. Its memory-centric compute architecture spans the Corsair inference accelerator, the JetStream accelerator-to-accelerator interconnect, the SquadRack rack-scale system, and the 3DIMC 3D digital in-memory compute technology, complemented by the open-source dmx-compressor (DMX) PyTorch toolkit for model co-design. This is an API Evangelist network profile; d-Matrix is a compute-hardware company and does not currently publish a public web API.

## Products
- Corsair — datacenter AI inference accelerator (chiplet-based, models up to 100B parameters)
- JetStream — accelerator-to-accelerator communications platform
- SquadRack — disaggregated, standards-based rack-scale inference solution
- 3DIMC — 3D stacked digital in-memory compute
